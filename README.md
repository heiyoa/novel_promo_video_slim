# 小说推文视频自动生成工作流

英文目录名：`novel_promo_video_slim`

## 概述

`novel_promo_video_slim` 是一个围绕小说推广内容构建的自动化工作流，用于将书单或原始内容整理为适合短视频链路继续处理的结构化结果。

项目的重点不在单一模型调用，而在于将“数据选择、推广补抓、脚本加工、视频链路调度、结果输出”组织成一条可分段执行的工作流。

## 场景示例

以一批待推广小说书目为例，系统需要完成以下处理：

1. 选出目标书目
2. 按需补抓推广信息
3. 组织文案与视频链路所需输入
4. 调用后续视频模块
5. 输出本次任务结果和中间文件

这类输出可直接用于后续草稿生成、图像生成、字幕生成或内容审阅。

## 设计目标

- 将内容生产链路拆为可单独验证的步骤
- 保证每一步存在明确输入输出
- 支持跳过部分重型模块做 smoke 检查
- 保留统一的结果文件，便于排查与复盘

## 模块划分

### `run_workflow.py`
负责整条工作流的调度，是主入口文件。

### `config/`
负责集中管理系统配置和流程配置。

### `modules/providers.py`
负责读取数据源并选择目标书目。

### `modules/promo_fetcher.py`
负责补抓推广信息，用于完善后续内容加工输入。

### `modules/video_pipeline.py`
负责组织脚本、图像、字幕、草稿等视频相关链路。

### `outputs/`
负责保存本次任务的结构化结果与中间产物。

## 工作流实现

整条链路的实现方式如下：

1. `run_workflow.py` 读取系统配置与工作流配置
2. `providers.py` 选择目标书目
3. `promo_fetcher.py` 补抓必要推广字段
4. `video_pipeline.py` 组织后续视频处理输入
5. 结果统一输出到 `outputs/`

在 `video_pipeline.py` 中，流程进一步分为：

1. 构造小说文本输入
2. 调用改写模块生成脚本
3. 调用字幕模块生成 SRT
4. 准备图像提示词
5. 根据配置决定是否继续进入图像、草稿和导出链路

这种结构保证了主调度层与具体视频处理模块分离，便于后续替换具体实现。

## 容灾与稳定性设计

### 1. 支持分段执行
可通过参数跳过 promo 或 video 模块，先验证前置链路是否正常。

### 2. 配置集中管理
路径、开关与任务行为通过配置统一控制，减少硬编码依赖。

### 3. 统一结果输出
每轮任务都会写出结构化结果文件，方便定位具体失败阶段。

### 4. 主链路与重型模块分离
在不触发图像和视频模块的情况下，仍可完成最小 smoke 验证。

## 当前状态
